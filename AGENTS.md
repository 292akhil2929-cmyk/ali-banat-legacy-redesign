# Project workflow preference

- When the user asks to create or modify a project in a new chat, create or use a new repository for that project when the repository is not already specified.
- Deploy the completed project to Vercel after validation.
- Before deployment, verify the repository, Vercel project, production URL, and responsive UI states.
- If repository or Vercel credentials/project ownership are ambiguous, ask for the missing repository or account detail instead of deploying to an unrelated project.
